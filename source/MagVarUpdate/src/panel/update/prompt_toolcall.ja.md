# 応答フォーマット

応答形式によって、追加モデル解析で接続先に求める機能と、変数更新の安定性が変わります。

- **チャットメッセージ**：最も互換性が高く、接続先の追加機能は不要です。安定性は、モデルが指定形式を守れるかに依存します。
- **ツール呼び出し**：接続先がtools/function callingに対応している必要があります。本文の混入を減らせますが、非対応のモデルやプロキシではエラーや機能低下が起きます。
- **フォーマット出力**：OpenAI互換の`response_format.json_schema`に対応している必要があります。応答が構造化JSONに制約されるため、通常はJSONPatchによる変数更新に適しています。
- **フォーマット出力（v4互換）**：dsv4fなど、`response_format.type = json_object`だけに対応する接続先向けです。追加モデルの出典が**カスタム**の場合だけ使えます。

`response_format.json_schema`への対応が確認できている場合は、まずフォーマット出力を試してください。非対応ならv4互換形式かチャットメッセージを使い、tools/function callingに対応していればツール呼び出しも試せます。

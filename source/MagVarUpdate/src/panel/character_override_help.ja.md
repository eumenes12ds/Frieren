# 現在のキャラクターカードの設定

ほかのフレームワークや専用画面と組み合わせて使うカードでは、追加モデル解析などが想定どおりの更新方式とワールドブック項目を使うよう、MVUの設定をあらかじめ指定する必要があります。

この欄で明示した正規表現以外の設定は、対応するユーザー設定を上書きします。**ユーザー設定に従う**を選んだ項目は上書きしません。カード側のワールドブック項目の許可・除外リストの正規表現は、ユーザー設定の規則と併用されます。いずれかの許可規則に一致すれば許可され、いずれかの除外規則に一致すれば除外されます。

たとえばカード側で**自動リクエスト**を**無効**にすると、ユーザー設定にかかわらず、AIの返信後に追加モデル解析を自動実行しません。**追加モデル解析を再試行**を押して手動実行することはできます。

許可・除外リストは、追加モデル解析リクエストのワールドブック項目だけに作用します。項目の`comment`がユーザー側またはカード側のいずれかの除外規則に一致すると、その項目はリクエストから除かれます。`[mvu_update]`を含む項目は、許可・除外リストの影響を受けません。
